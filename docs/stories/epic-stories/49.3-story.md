### User story

As **ops**, I want `--verify` on target install to run doctor and serve dry-run, so that I know the deploy bundle is healthy before going live.

### Upstream integration — [E2-S04c](05.3-story.md#e2-s04c-zaumzeug-doctor-deploy-mode) *(Done)*

[E2-S04c](05.3-story.md) provides the deploy-bundle doctor this story calls. **Do not reimplement** manifest or artifact validation in `target_install.py` — delegate to doctor.

| Contract | Value |
|---|---|
| **CLI (AC-1)** | `zaumzeug doctor <name> --deploy` |
| **Env alternative** | `HARNESS_ROOT=deploy zaumzeug doctor <name>` |
| **Programmatic** | `zaumzeug.doctor.run_doctor(harness_name=<name>, deploy=True)` |
| **Harness root** | `deploy/<name>/` relative to project root ([§8.1](../../architecture/06-runtime-and-protocols.md#81-source-roots)) |
| **Exit code** | `0` when all checks pass; `1` when any check **fails** (warnings are non-blocking) |
| **Validates** | Deploy `manifest.json` (§10.3), pinned `artifact-manifest.json` paths, plus E2-S04a core checks (config, models, runtime paths, port) |

Completing **AC-1** here closes [E2-S04c DoD](05.3-story.md#definition-of-done) *Called by E5-S09c `--verify`*.


### Upstream integration — [E2-S05](06-story.md#e2-s05-dry-run-on-serve) *(Done)*

[E2-S05](06-story.md) provides the serve dry-run this story calls. **Do not reimplement** config validation or resolver output in `target_install.py` — delegate to serve.

| Contract | Value |
|---|---|
| **CLI (AC-2)** | `zaumzeug serve <name> --deploy --dry-run` |
| **Programmatic** | `zaumzeug.serve.validate_serve(harness_name=<name>, deploy=True)` |
| **Harness root** | `deploy/<name>/` relative to project root ([§8.1](../../architecture/06-runtime-and-protocols.md#81-source-roots)) |
| **Exit code** | `0` when validation passes; `1` on config or resolution failure |
| **Validates** | `load_harness()`, workflow entry via `resolve_serve_entry()`, model registry and runtime paths for entry agent; deploy manifest when `--deploy` |

Completing **AC-2** here closes [E2-S05 DoD](06-story.md#definition-of-done) *target_install `--verify` uses serve dry-run*.
