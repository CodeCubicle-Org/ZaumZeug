### User story

As a **harness developer**, I want the runtime to apply exported input-rewrite templates before the agent loop, so that compile-time optimized clarify/rewrite text is used without GEPA at serve time.

### Implementation notes (2026-07-28)

- `zaumzeug.runtime.preprocess` loads optional `paths.input_rewrite` from `artifact-manifest.json` (legacy `manifest.json` accepted) and applies Jinja / `str.format` / plain-text prepend before `Agent.run`.
- Factory `build_agent_bundle()` returns `BuiltAgent` with `input_rewrite_template`; serve (`AgentPipelineWrapper`) and `run_workflow` apply preprocess on the request path.
- No `dspy` / `gepa` imports on preprocess, factory, workflow, or serve runner modules.
